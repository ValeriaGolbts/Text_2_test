# Text_2_test
Разработка системы автоматической генерации тестовых заданий на основе мультимодальных образовательных материалов, интегрированной в Telegram-бот.

# Архитектура системы
Text_2_test/
├── src// # Модуль предобработки текста

├── src/generator/ # Модуль работы с GigaChat
│ 

├── src/shared/ # Общие утилиты
│

├── tests/ # Тесты
│

└── requirements.txt # Зависимости Python
